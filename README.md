# 數學 重點整理（高職一年級　第一章 坐標系與函數圖形）

Mathematics study notes for Taiwanese vocational high school students (高職 / 技高).

**線上閱讀：https://math-lac-rho.vercel.app**

## 內容

| 單元 | 重點 |
|---|---|
| 1-1 實數 | 實數系、算幾不等式、循環小數、根式運算、乘法公式、區間 |
| 1-2 絕對值與平面直角坐標系 | 絕對值不等式、兩點距離、內分點、中點、重心、對稱點 |
| 1-3 常見的函數圖形 | 集合與函數、一次函數、二次函數（配方、頂點、判別式）、圖形平移 |
| 1-4 一元二次不等式 | 恆正與恆負、二次不等式的解（D > 0、D = 0、D < 0）、根與係數 |

## 特色

- 公式的每個代號上方標示中文名稱，除法寫成上下分數，方便背誦
- 每節附陷阱提醒與例題
- 網頁版有「拋物線練習器」，拉動 a、b、c 就能看圖形變化
- 淺色／深色模式切換；在空白背景連點兩下，回到最上面的目錄
- 手機、平板、電腦都能閱讀
