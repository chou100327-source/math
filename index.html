1-1實數

先搞懂

數是一步一步「擴大」出來的：數東西用自然數，有欠債就需要負數，分東西需要分數，量正方形的對角線又發現了無理數。全部合在一起，就是我們在高中數學裡用的「實數」，數線上的每一個點，都剛好對應一個實數。

一、實數系的分類

每一個圈都包在比它大的圈裡面

數系符號包含什麼例子
自然數（正整數）ℕ1, 2, 3, …1, 2, 3
整數ℤ正整數、零、負整數−3, 0, 5
有理數ℚ能寫成「整數 ÷ 整數（分母 ≠ 0）」的數，包含整數、有限小數、循環小數1／3、−2、0.25、0.333…
無理數—不循環的無限小數，不能寫成分數π、√2、√3、∛2
實數ℝ有理數 + 無理數全部
有理數：q整數p整數（p ≠ 0，p、q 都是整數）
  • 整數、有限小數、循環小數都是有理數。例如 0.25 = 1／4、0.333… = 1／3。
  • 開方「開不盡」的數是無理數：√2、√3 是無理數；但 √4 = 2 是整數，所以是有理數。
  • 有理數 + 有理數 = 有理數；有理數（≠ 0）× 無理數 = 無理數；但兩個無理數相加不一定是無理數，例如 √2 + (−√2) = 0。

二、循環小數化成分數

循環小數的小數點後面，有一段數字一直重複，重複的那一段叫「循環節」，寫的時候在上面畫一條橫線。化成分數的想法是：乘上 10 的幾次方，讓兩個數的小數部分一模一樣，再相減把循環部分消掉。

例題：推導

設 x = 0.3 = 0.333…，則 10x = 3.333…，兩式相減：9x = 3，x = 1／3。

設 x = 0.12 = 0.1222…，10x = 1.222…，100x = 12.222…，兩式相減：90x = 11，x = 11／90。

類型快速做法例子
純循環（一開始就循環）循環節 ÷ 同位數的 90.3 = 3／9 = 1／3；0.12 = 12／99 = 4／33
混循環（先有不循環的數字）(全部數字 − 不循環部分) ÷ (循環幾位就幾個 9，後面補不循環位數個 0)0.12 = (12 − 1)／90 = 11／90
帶整數整數部分另外加1.3 = 1 + 1／3 = 4／3

四、根式運算

√a正數 × √b正數 = √(a正數b正數)√a正數√b正數 = √a正數b正數√(a實數²) = |a實數|
  • 化簡：把根號裡的完全平方數提出來。√12 = √(4 × 3) = 2√3；√72 = 6√2。
  • 加減：只有「根號部分相同」（同類根式）才能合併。2√3 + 5√3 = 7√3；√2 + √3 不能再合併。
  • 分母有理化：不要讓分母有根號。單項：6√3 = 6√33 = 2√3。

分母是兩項（帶根號）時，要乘上它的「共軛」，利用平方差公式 (a + b)(a − b) = a² − b² 把根號消掉：

1√a正數 + √b正數 = √a正數 − √b正數a正數 − b正數

雙重根號（根號裡還有根號）：因為 (√a + √b)² = a + b + 2√(ab)，所以只要找兩個數，相加是前面那個數、相乘是根號裡的數，就能化簡。

√(a大的數 + b小的數 ± 2√(a大的數b小的數)) = √a大的數 ± √b小的數
例題：根式練習

√(5 + 2√6)：相加 5、相乘 6 的兩數是 3 和 2，所以 = √3 + √2。

√(7 − 4√3) = √(7 − 2√12)：相加 7、相乘 12 的兩數是 4 和 3，所以 = √4 − √3 = 2 − √3（大的減小的，結果才是正數）。

1√3 − √2 = √3 + √2(√3)² − (√2)² = √3 + √23 − 2 = √3 + √2。

五、乘法公式

(a第一項 + b第二項)² = a第一項² + 2a第一項b第二項 + b第二項²(a第一項 − b第二項)² = a第一項² − 2a第一項b第二項 + b第二項²(a第一項 + b第二項)(a第一項 − b第二項) = a第一項² − b第二項²

這三個公式在化簡、配方、因式分解裡都會用到，要熟到不用想。例如 99² = (100 − 1)² = 10000 − 200 + 1 = 9801。

六、算幾不等式

a非負實數 + b非負實數2 ≥ √(a非負實數b非負實數)（算術平均數 ≥ 幾何平均數）

為什麼？任何實數的平方都 ≥ 0，所以 (√a − √b)² ≥ 0，展開得 a + b − 2√(ab) ≥ 0，移項就是 a + b ≥ 2√(ab)。等號只有在 √a = √b，也就是 a = b 時才成立。

  • 和固定時，積有最大值：a + b = S，則 ab ≤ (S／2)²，a = b 時最大。
  • 積固定時，和有最小值：ab = P，則 a + b ≥ 2√P，a = b 時最小。
  • 使用前提：a、b 都要是非負數（求最小值時通常是正數）。
例題：求最小值

x > 0，求 x + 4x 的最小值：x + 4／x2 ≥ √(x × 4x) = 2，所以 x + 4x ≥ 4，等號在 x = 4x，即 x = 2 時成立。

例題：求最大值

兩正數 a + b = 10，求 ab 的最大值：a + b2 = 5 ≥ √(ab)，所以 ab ≤ 25，在 a = b = 5 時成立。也就是周長 20 的長方形，正方形（5 × 5）面積最大。

七、區間與數線

寫法不等式數線名稱

(a, b)a < x < b兩端空心點開區間

一句話記住

實數 = 有理數 + 無理數；循環小數化分數用「乘 10 的幾次方再相減」；(a + b)／2 ≥ √(ab)，a = b 時等號成立；不等式乘負數要反向。

陷阱

0.9 = 1（因為 9／9 = 1）。√(a + b) ≠ √a + √b。π 是無理數，3.14 和 22／7 只是近似值。算幾不等式只能用在非負數，而且等號成立的條件（a = b）要檢查能不能達到。

1-2絕對值與平面直角坐標系

先搞懂

絕對值就是「到原點的距離」：不管這個數是正是負，距離一定是正的（或 0）。把數線再加上一條垂直的線，就成了平面坐標系，可以用兩個數來表示平面上的任何一點，並計算距離、中點、重心。

一、絕對值的定義與性質

|a實數| = a實數（a ≥ 0）；|a實數| = −a實數（a < 0）數線上兩點 A(a)、B(b) 的距離 = |a點A坐標 − b點B坐標|√(a實數²) = |a實數|
  • |k| = |k − 0|，表示坐標為 k 的點到原點的距離。
  • 性質：|a| ≥ 0；|−a| = |a|；|ab| = |a| × |b|；|a／b| = |a|／|b|（b ≠ 0）；|a + b| ≤ |a| + |b|（三角不等式）。

二、絕對值方程式與不等式

把絕對值想成距離：|x − c| 就是「x 到 c 的距離」，所以：

式子（r > 0）意思解
|x − c| = rx 到 c 的距離剛好是 rx = c + r 或 x = c − r
|x − c| < r（≤ r）距離小於 r：夾在中間c − r < x < c + r（可含等號）
|x − c| > r（≥ r）距離大於 r：跑兩邊x > c + r 或 x < c − r

口訣：小於夾中間（「且」），大於跑兩邊（「或」）。

例題：解絕對值

|x − 2| = 3 → x − 2 = 3 或 x − 2 = −3 → x = 5 或 −1。

|x − 2| < 3 → −3 < x − 2 < 3 → −1 < x < 5（距離 2 不超過 3 的點）。

|2x − 1| ≥ 5 → 2x − 1 ≥ 5 或 2x − 1 ≤ −5 → x ≥ 3 或 x ≤ −2，即 x ≥ 3 或 x ≤ −2。

|x + 1| ≤ 4 → −4 ≤ x + 1 ≤ 4 → −5 ≤ x ≤ 3。

例題：特殊情況

|x| = −3：絕對值不可能是負數，無解。|x| > −2：永遠成立，解是所有實數。|x| < −2：無解。

|x − 1| = |x + 3|：x 到 1 和到 −3 的距離一樣，x 是 1 和 −3 的中點，x = −1。

三、平面直角坐標系

x 軸和 y 軸把平面分成四個象限

  • 兩條互相垂直的數線，交在原點 O，水平的叫 x 軸、鉛直的叫 y 軸。平面上的每一個點，都用 (x, y) 表示。
  • 在 x 軸或 y 軸上的點，不屬於任何象限。
點 (a, b) 的對稱點結果記法
對 x 軸(a, −b)y 變號
對 y 軸(−a, b)x 變號
對原點(−a, −b)兩個都變號
對直線 y = x(b, a)x、y 交換

四、兩點距離公式

A(1, 2) 與 B(4, 6)：橫向差 3、直向差 4，做出直角三角形，AB = √(3² + 4²) = 5

AB = √((x₁A的x − x₂B的x)² + (y₁A的y − y₂B的y)²)

這就是畢氏定理：斜邊² = 橫向差² + 直向差²。x、y 的差先平方再相加，所以誰減誰（先後順序）都沒有關係。

五、內分點、中點、重心

點 P 在線段 AB 上，且 AP : PB = m : n，稱 P 為 AB 的內分點。P 在從 A 走向 B 的路上，走了全長的 m／(m + n)：P = A + mm + n × (B − A)，整理後得到：

P = ( n後段比x₁A的x + m前段比x₂B的xm前段比 + n後段比 , n後段比y₁A的y + m前段比y₂B的ym前段比 + n後段比 )中點（m : n = 1 : 1）：( x₁A的x + x₂B的x2 , y₁A的y + y₂B的y2 )△ABC 的重心：( x₁A的x + x₂B的x + x₃C的x3 , y₁A的y + y₂B的y + y₃C的y3 )
  • 口訣：「靠近誰，就乘另一邊的比」：靠近 A（m 小）的點，A 的坐標要乘上較大的那個比（n）。
  • 重心是三條中線的交點，把每條中線分成 2 : 1；它的坐標就是三個頂點坐標的平均。
例題：距離、分點、中點、重心

A(1, 2)、B(7, 8)：AB = √(6² + 6²) = √72 = 6√2。

AP : PB = 1 : 2（m = 1、n = 2）：P = ( 2 × 1 + 1 × 73 , 2 × 2 + 1 × 83 ) = (3, 4)；中點 = ( 1 + 72 , 2 + 82 ) = (4, 5)。

△ABC：A(1, 2)、B(5, 4)、C(3, 9)，重心 = ( 1 + 5 + 33 , 2 + 4 + 93 ) = (3, 5)。

一句話記住

絕對值是距離：|x − c| < r 夾中間、> r 跑兩邊；兩點距離 = √(Δx² + Δy²)；內分點「靠近誰、乘另一邊的比」；重心 = 三點坐標的平均。

陷阱

在 x 軸或 y 軸上的點不屬於任何象限。內分點公式容易把比例乘反：先確認 P 比較靠近哪一點，再檢查答案是不是真的落在那一邊。絕對值不等式如果右邊是負數，要先判斷有沒有解。

1-3常見的函數圖形

先搞懂

函數就像一台「輸入輸出機器」：你丟一個數 x 進去，它就吐出唯一一個數 y。這一節要認識三種最常見的函數：一次函數（直線）、常數函數（水平線）、二次函數（拋物線），並學會從式子判斷圖形的樣子。

一、集合與元素

  • 集合：一些「明確」的事物放在一起，通常用大寫英文字母表示，元素寫在大括號裡。
  • 列舉法：A = {2, 4, 6}，A 裡面有 3 個元素。
  • 描述法：B = {x ｜ 0 ≤ x ≤ 10，x 為實數}，意思是「所有滿足 0 ≤ x ≤ 10 的實數 x」。
  • 「2 屬於 A」寫成 2 ∈ A；「5 不屬於 A」寫成 5 ∉ A。

二、函數的定義

設 A、B 是兩個集合。如果對 A 裡的每一個元素 x，在 B 裡都找得到唯一一個元素 y 和它對應，就稱「y 是 x 的函數」，寫成 y = f(x)。

名詞意思
自變數 x輸入的數（自己可以變動）
應變數 y輸出的數（跟著 x 變動）
定義域 Ax 可以代入的範圍（集合 A）
對應域 By 所在的集合；實際輸出的所有 y 叫值域
  • 圖形判斷：畫一條鉛直線，如果這條線掃過圖形時，每一個位置最多只碰到圖形一次，這個圖形就是函數。
  • 函數值：f(a) 就是把 x = a 代進去算出的 y。例如 f(x) = 2x² − 3x + 1：f(2) = 8 − 6 + 1 = 3，f(−1) = 2 + 3 + 1 = 6。
  • 定義域的限制：分母不能是 0（f(x) = 1／(x − 2) 要 x ≠ 2）；根號裡不能是負數（f(x) = √(x − 1) 要 x ≥ 1）。

三、一次函數與常數函數（直線）

一次函數：y函數值 = a斜率x自變數 + by截距（a ≠ 0）常數函數：y函數值 = b常數斜率 m斜率 = y₂B的y − y₁A的yx₂B的x − x₁A的x
一次函數 y = ax + b圖形
a > 0直線往右上升
a < 0直線往右下降
b直線和 y 軸的交點 (0, b)（y 截距）
常數函數 y = b一條水平線（a = 0，斜率為 0）

一次函數和常數函數合稱「線型函數」，圖形都是直線。斜率 a 就是「x 增加 1，y 增加多少」。

已知兩點求直線：先求斜率 m，再用「點斜式」：y − y₁ = m(x − x₁)。

例題：求直線

過 (1, 2) 與 (3, 8)：斜率 m = 8 − 23 − 1 = 3，點斜式 y − 2 = 3(x − 1)，整理得 y = 3x − 1。

四、二次函數（拋物線）

二次函數 f(x) = ax² + bx + c（a ≠ 0）的圖形叫拋物線。想知道它長什麼樣子，最好的方法是配方，把它變成頂點式。

  1. 提出 x² 的係數 a：ax² + bx + c = a(x² + bax) + c。
  2. 括號裡配成完全平方：加上再減掉 (b2a)²。
  3. 整理成 a(x − h)² + k 的形式，h 和 k 就是頂點坐標。

例題：配方與頂點

y = x² − 4x + 1 = (x − 2)² − 3，頂點 (2, −3)，對稱軸 x = 2，開口向上，最小值 −3。D = 16 − 4 = 12 > 0，和 x 軸交兩點。

例題：應用題：最大面積

用 20 公尺的圍籬圍一個長方形，長 x、寬 10 − x，面積 A = x(10 − x) = −x² + 10x = −(x − 5)² + 25。

頂點在 x = 5，a < 0 有最大值：長 = 寬 = 5 時，面積最大 = 25 平方公尺（和算幾不等式的結論一樣）。

  • 二次函數的基本圖形 y = ax²，平移後得到 y = a(x − h)² + k，形狀（開口大小與方向）不變。
  • 絕對值函數 y = |x| 是 V 字形，頂點在原點；y = |x − h| + k 的頂點是 (h, k)。

函數：每個 x 只有一個 y；一次函數是直線（斜率 a）；二次函數配方成 a(x − h)² + k，頂點 (h, k)，a > 0 開口向上有最小值、a < 0 向下有最大值；D 決定和 x 軸有幾個交點。

陷阱

y = (x + 2)² 的頂點在 (−2, 0)，不是 (2, 0)。求最大、最小值前先看 a 的正負。配方時，提出 a 之後括號裡的一次項係數要「除以 a」，再除以 2、再平方。

1-4一元二次不等式

先搞懂

解一元二次不等式（例如 x² − x − 6 > 0），最好的方法是看圖：把 ax² + bx + c 想成一條拋物線，「> 0」就是問「拋物線在 x 軸上方」的那些 x，「< 0」就是問「在 x 軸下方」的 x。

三、解題步驟

  1. 移項：把所有項移到左邊，右邊變成 0。
  2. 讓 x² 的係數變正：如果是負的，兩邊同乘 −1，不等號要反向。
  3. 找根：用因式分解或公式解，求出兩根（或判斷有沒有實根）。
  4. 看圖或查表，寫出解的範圍；最後可以用區間表示。
例題：基本題

x² − x − 6 > 0：(x − 3)(x + 2) > 0，兩根 α = 3、β = −2，「大於跑兩邊」→ x > 3 或 x < −2。

−x² + 4x − 3 ≥ 0：兩邊乘 −1 得 x² − 4x + 3 ≤ 0（反向），(x − 1)(x − 3) ≤ 0，「小於夾中間」→ 1 ≤ x ≤ 3。

x² − 2x + 1 ≤ 0：(x − 1)² ≤ 0，只有 x = 1；x² − 2x + 1 > 0 則是 x ≠ 1。

x² + 1 > 0：D = −4 < 0，所有實數；x² + 1 < 0 無解。

例題：反推不等式

已知解為 1 < x < 3：兩根 1 和 3，「夾中間」是小於 0：(x − 1)(x − 3) < 0，即 x² − 4x + 3 < 0。

五、分式不等式與應用

分式不等式可以轉成二次不等式，但要注意分母不能是 0：

例題：分式不等式

x − 3x + 2 > 0 → 分子分母同號 → (x − 3)(x + 2) > 0 → x > 3 或 x < −2。

x − 3x + 2 ≤ 0 → (x − 3)(x + 2) ≤ 0 且 x ≠ −2 → −2 < x ≤ 3（−2 要排除，因為分母不能是 0）。

例題：應用題：利潤

某店賣 x 杯飲料的利潤函數是 f(x) = x² − 8x − 240（元），至少要賣幾杯才不虧本？

要 f(x) ≥ 0：(x − 20)(x + 12) ≥ 0 → x ≥ 20 或 x ≤ −12。杯數不能是負的，所以至少要賣 20 杯（f(20) = 400 − 160 − 240 = 0）。

一句話記住

看圖：拋物線在 x 軸上方是「> 0」、下方是「< 0」；D > 0 時「大於跑兩邊、小於夾中間」；恆正是 a > 0 且 D < 0；x² 係數是負的先乘 −1 並反向。

陷阱

x² 的係數是負的時候，一定要先乘 −1 並把不等號反過來，才能套「大於兩邊、小於中間」。分式不等式不能直接去分母（分母的正負不確定），要轉成「乘積」並排除讓分母為 0 的值。

三角函數

2-1有向角及其度量

先搞懂

國中學的角只有 0° 到 180°，而且沒有「方向」。這一章要把角擴大：可以轉很多圈、可以順時針轉，所以需要「有向角」；而且除了「度」，還要認識另一種更適合計算的單位「弧度」。

一、有向角

標準位置的角：始邊固定在正 x 軸，終邊轉動的方向和大小決定角的正負與大小

  • 角是由始邊轉到終邊形成的。逆時針轉是正角，順時針轉是負角。
  • 標準位置：把頂點放在原點、始邊放在正 x 軸。這樣一個角就由終邊決定，終邊落在第幾象限，這個角就叫第幾象限角。
  • 角度可以超過 360°（轉了一圈以上），例如 400°；也可以是負的，例如 −30°。
終邊位置角的範圍（0° ≤ θ < 360°）
第一象限0° < θ < 90°
第二象限90° < θ < 180°
第三象限180° < θ < 270°
第四象限270° < θ < 360°
在坐標軸上θ = 0°、90°、180°、270°（不屬於任何象限，叫「界限角」）

二、同界角

終邊相同的角叫同界角：把一個角加上或減去 360° 的整數倍，終邊的位置不會變。

與 θ角 同界的角：θ角 + 360° × k整數（k 是整數）
例題：同界角

400° − 360° = 40°（最小正同界角）；−30° + 360° = 330°；750° − 2 × 360° = 30°。

求 −400° 的最小正同界角：−400° + 2 × 360° = 320°，所以它是第四象限角。

三、角度的單位：度、分、秒

  • 1° = 60′（分），1′ = 60″（秒）。
  • 25°30′ = 25 + 30／60 = 25.5°；38.25° = 38° + 0.25 × 60′ = 38°15′。

弧度是用「弧長 ÷ 半徑」來表示角的大小。圓周長是 2πr，所以一圈的弧度是 2πr ÷ r = 2π，對應 360°：

陷阱

用弧長、面積公式時，θ 一定要先換成弧度，不能直接代度數。同界角是加減 360°（不是 180°）。負角「順時針」轉，不要把方向搞反。

2-2三角函數的定義與性質

先搞懂

三角函數就是用直角三角形的邊長比來描述角的大小。直角三角形不管大小，只要有一個銳角一樣，三邊的「比值」就一樣，所以可以用這些比值當作這個角的「代號」。

一、六個三角函數（銳角）

θ 的「對邊」是不靠著 θ 的那邊，「鄰邊」是靠著 θ 的那一邊（不是斜邊）

sinθ角 = 對邊斜邊cosθ角 = 鄰邊斜邊tanθ角 = 對邊鄰邊cscθ角 = 斜邊對邊secθ角 = 斜邊鄰邊cotθ角 = 鄰邊對邊

口訣：「正弦對斜、餘弦鄰斜、正切對鄰」。後三個 csc、sec、cot 是前三個的倒數（csc = 1／sin，sec = 1／cos，cot = 1／tan）。

30°–60°–90° 的直角三角形三邊比是 1 : √3 : 2；45°–45°–90° 的三邊比是 1 : 1 : √2。由這兩個三角形就能算出下面的值：

三、基本關係式

倒數：sinθ角 × cscθ角 = 1，cosθ角 × secθ角 = 1，tanθ角 × cotθ角 = 1商數：tanθ角 = sinθ角cosθ角，cotθ角 = cosθ角sinθ角平方：sin²θ角 + cos²θ角 = 11 + tan²θ角 = sec²θ角1 + cot²θ角 = csc²θ角

平方關係怎麼來的？直角三角形對邊 a、鄰邊 b、斜邊 c，畢氏定理 a² + b² = c²。兩邊同除以 c²：(a／c)² + (b／c)² = 1，也就是 sin²θ + cos²θ = 1。同除以 b²，就得到 1 + tan²θ = sec²θ。

餘角關係：sin(90° − θ角) = cosθ角，cos(90° − θ角) = sinθ角，tan(90° − θ角) = cotθ角
例題：由邊長求函數值

直角三角形 θ 的對邊 3、鄰邊 4，斜邊 = √(9 + 16) = 5：sin θ = 3／5、cos θ = 4／5、tan θ = 3／4。

已知銳角 θ 的 sin θ = 5／13：對邊 5、斜邊 13，鄰邊 = √(169 − 25) = 12，所以 cos θ = 12／13、tan θ = 5／12。

例題：特殊角的計算

sin²30° + cos²60° = (1／2)² + (1／2)² = 14 + 14 = 1／2。

sin 30° × cos 60° + tan 45° = 12 × 12 + 1 = 5／4。

例題：仰角與高度

站在離大樓 20 公尺處，看大樓頂端的仰角是 30°：高度 = 20 × tan 30° = 20 × √33 = 20√33 ≈ 11.5 公尺。

一句話記住

正弦＝對／斜、餘弦＝鄰／斜、正切＝對／鄰；sin² + cos² = 1；tan = sin／cos；特殊角值要背熟。

陷阱

「對邊」和「鄰邊」是相對於所選的角 θ 而言的，換一個角，對邊與鄰邊就互換。tan 90° 沒有定義（鄰邊 = 0，不能除以 0）。

2-3任意角的三角函數

先搞懂

直角三角形裡的角只能是銳角。要處理任意大小的角（鈍角、超過 360°、負角），就把角放到坐標平面上，用終邊上一個點的坐標來定義三角函數。

一、用坐標定義

把角 θ 放在標準位置，在終邊上任取一點 P(x, y)，設 r = OP = √(x² + y²)（r > 0），則：

sinθ角 = y縱坐標r距離cosθ角 = x橫坐標r距離tanθ角 = y縱坐標x橫坐標（x ≠ 0）cscθ角 = r距離y縱坐標secθ角 = r距離x橫坐標cotθ角 = x橫坐標y縱坐標（y ≠ 0）

取 r = 1（單位圓）時，終邊與圓的交點坐標就是 (cos θ, sin θ)

  • 對於銳角，這個定義和 2-2 的「對邊／斜邊」完全一樣（對邊 = y、鄰邊 = x、斜邊 = r）。
  • r 是正的；x、y 可能是正、負或 0，所以三角函數值可能是負的。
  • 無定義的情況：x = 0（θ = 90°、270°）時 tan、sec 無定義；y = 0（θ = 0°、180°）時 csc、cot 無定義。
例題：由點求函數值

終邊通過 P(−3, 4)：r = √(9 + 16) = 5，sin θ = 4／5、cos θ = −3／5、tan θ = −4／3（第二象限）。

終邊通過 P(−5, −12)：r = 13，sin θ = −12／13、cos θ = −5／13、tan θ = 12／5（第三象限）。

2-4三角函數的圖形與週期

先搞懂

把 θ 從 0 慢慢增加，畫出 sin θ 的值，會得到一條像波浪一樣一直重複的曲線。聲音、光、交流電、潮汐，都是這種波，所以三角函數的圖形非常重要。

五、怎麼畫（五點法）

  1. 先算週期 T 和振幅 |a|，決定從哪裡開始（bx + c = 0 的位置）。
  2. 把一個週期分成四等分，得到五個關鍵點（起點、1/4、2/4、3/4、終點）。
  3. 依序填上 0、最大、0、最小、0（sin 的情況；a 為負時最大最小對調），再加上中線 d。
  4. 用平滑曲線連起來，再往左右重複。

y = 3 sin 2x：振幅 3、週期 2π ÷ 2 = π，值域 −3 ≤ y ≤ 3。

y = 2 cos(x／2) + 1：振幅 2、週期 2π ÷ (1／2) = 4π，最大值 1 + 2 = 3、最小值 1 − 2 = −1。

y = sin(x − π／3)：振幅 1、週期 2π，圖形向右平移 π／3。

y = −2 sin x：振幅 2，圖形上下顛倒；y = tan 2x：週期 π ÷ 2 = π／2。

一句話記住

sin、cos 週期 2π、值域 [−1, 1]；tan 週期 π、值域全體實數；y = a sin(bx + c) + d：振幅 |a|、週期 2π／|b|、中線 d。

陷阱

週期是 2π ÷ |b|，不是 2π × b。tan 的週期是 π（不是 2π）。振幅一定是正的（取絕對值），a 為負只是上下顛倒。

2-5正弦定理與餘弦定理

先搞懂

直角三角形用邊長比就能算。可是一般的三角形（沒有直角）呢？只要知道其中三個量（至少一個是邊），就可以用正弦定理或餘弦定理把其他的邊和角都算出來。

一、符號

習慣用大寫 A、B、C 表示角，小寫 a、b、c 表示它們對面的邊

二、正弦定理

a邊asinA角A = b邊bsinB角B = c邊csinC角C = 2R外接圓半徑
  • 邊和它對角的正弦成正比；比值等於外接圓直徑 2R。
  • 為什麼？從 C 作高 h，h = b sin A = a sin B，所以 a／sin A = b／sin B；對另一個高同樣處理就得到全部相等。
  • 適用時機：已知「兩角一邊」（AAS、ASA），或「兩邊和其中一邊的對角」（SSA）。

三、餘弦定理

a邊a² = b邊b² + c邊c² − 2b邊bc邊c cosA角AcosA角A = b邊b² + c邊c² − a邊a²2b邊bc邊c
  • 它是畢氏定理的推廣：當 A = 90° 時 cos A = 0，就是 a² = b² + c²。
  • 為什麼？從 B 作高，把 a 當成直角三角形的斜邊，用畢氏定理就能推出來。
  • 適用時機：已知「兩邊和夾角」（SAS）求第三邊；或已知「三邊」（SSS）求角。
  • 同樣的形式還有 b² = a² + c² − 2ac cos B、c² = a² + b² − 2ab cos C。

面積 = 12 a邊ab邊b sinC角C = 12 b邊bc邊c sinA角A = 12 a邊ac邊c sinB角B

面積 = ½ × 兩邊 × 夾角的正弦（「底 × 高 ÷ 2」中的高就是另一邊 × sin 夾角）。

例題：正弦定理

△ABC 中，A = 30°、B = 45°、a = 4：C = 180° − 75° = 105°；a／sin A = 4 ÷ (1／2) = 8，所以 b = 8 × sin 45° = 8 × √22 = 4√2。

a = 6、A = 30°：2R = 61／2 = 12，外接圓半徑 R = 6。

例題：餘弦定理

b = 3、c = 5、A = 60°：a² = 9 + 25 − 2 × 3 × 5 × 12 = 34 − 15 = 19，a = √19。

正弦定理：a／sin A = b／sin B = c／sin C = 2R；餘弦定理：a² = b² + c² − 2bc cos A；面積 = ½ ab sin C。兩角一邊用正弦、兩邊夾角或三邊用餘弦。

陷阱

正弦定理中，邊要配它的對角（a 配 A）。SSA 可能有兩解，求出角之後要檢查三個內角和是否 180°。餘弦定理中「−2bc cos A」的 A，是 b、c 兩邊的夾角（也就是 a 的對角），不要用錯角。

03

平面向量

3-1向量及其基本運算

先搞懂

有些量只有「大小」（例如溫度、長度），有些量除了大小還有「方向」（例如位移、速度、力）。同時有大小和方向的量叫向量，用有方向的箭頭來表示：箭頭的長度是大小，箭頭指的方向是方向。

一、向量的基本概念

  • 有向線段 AB：起點是 A、終點是 B，記作 AB；也常用小寫字母 a 表示。
  • 長度（大小）：|a|，就是箭頭的長度。
  • 相等向量：大小和方向都相同，不管位置在哪裡（可以隨意平移）。
  • 負向量 −a：大小相同、方向相反。零向量 0：長度為 0，沒有方向。
  • 單位向量：長度等於 1 的向量。和 a 同方向的單位向量 = a ÷ |a|。

二、用坐標表示向量

A(x₁A的x, y₁A的y)、B(x₂B的x, y₂B的y)：AB = (x₂B的x − x₁A的x, y₂B的y − y₁A的y)
  • 向量的坐標 = 終點坐標 − 起點坐標（先終點、再起點，不能反）。
  • 兩個向量相等 ⇔ 它們的坐標相等。
  • 從原點出發的向量 OP 的坐標就是 P 點的坐標，叫 P 的位置向量。

三、向量的運算

加法：把 b 的起點接在 a 的終點，從 a 的起點連到 b 的終點，就是 a + b

運算幾何意義坐標（a = (a₁, a₂)、b = (b₁, b₂)）
加法 a + b三角形法（頭接尾），或平行四邊形法（共起點，取對角線）(a₁ + b₁, a₂ + b₂)
減法 a − ba + (−b)；也是「從 b 的終點指向 a 的終點」(a₁ − b₁, a₂ − b₂)
係數積 k ak > 0：同方向、長度變 k 倍；k < 0：反方向、長度變 |k| 倍(k a₁, k a₂)
長度 |a|箭頭的長度√(a₁² + a₂²)
|a向量| = √(a₁橫分量² + a₂縱分量²)單位向量 = a向量|a|（同方向、長度 1）

四、平行與線性組合

  • 平行：a ∥ b（b ≠ 0）⇔ 存在實數 k，使 a = k b。
  • 坐標判斷：a₁b₂ − a₂b₁ = 0（也就是對應坐標成比例）。
  • 線性組合：用 m a + n b 表示的向量。平面上任何向量，都能用兩個不平行的向量 a、b 的線性組合表示。
  • 分點的向量表示：AP : PB = m : n，則 P = n A + m Bm + n（A、B 是位置向量），和 1-2 的內分點公式一樣。
例題：向量的運算

A(1, 2)、B(4, 6)：AB = (4 − 1, 6 − 2) = (3, 4)，|AB| = √(9 + 16) = 5，AB 的單位向量 = (3／5, 4／5)。

a = (2, 3)、b = (1, −4)：a + b = (3, −1)；a − b = (1, 7)；2a − 3b = (4, 6) − (3, −12) = (1, 18)；|a| = √13。

例題：平行

(2, 3) 與 (4, 6)：2 × 6 − 3 × 4 = 0，所以平行（(4, 6) = 2 × (2, 3)）。

(k, 3) ∥ (2, 6)：k × 6 − 3 × 2 = 0 → k = 1。

例題：幾何應用

平行四邊形 ABCD 中，AC = AB + AD（對角線向量 = 兩鄰邊向量的和）；BD = AD − AB。

一句話記住

向量坐標 = 終點 − 起點；加減和係數積都是各坐標分別運算；|a| = √(a₁² + a₂²)；平行 ⇔ a₁b₂ − a₂b₁ = 0。

陷阱

向量坐標是「終點 − 起點」，順序不能反。向量只看大小和方向，不看位置；平行的向量長度可以不同，方向可以相反。

3-2向量的內積與夾角

先搞懂

兩個向量相加相減，結果還是向量。內積是另一種「乘法」：兩個向量一乘，結果是一個數（不是向量），這個數可以告訴我們兩個向量的夾角，以及它們有沒有互相垂直。

一、內積的定義

兩個向量的夾角 θ：把兩個向量的起點放在一起後，兩條箭頭之間的角（0° ≤ θ ≤ 180°）

a向量·b向量 = |a向量| |b向量| cosθ夾角坐標：(a₁橫分量, a₂縱分量)·(b₁橫分量, b₂縱分量) = a₁橫分量b₁橫分量 + a₂縱分量b₂縱分量

兩個公式為什麼一樣？對三角形用餘弦定理：|a − b|² = |a|² + |b|² − 2|a||b|cos θ。另一方面用坐標展開：|a − b|² = (a₁ − b₁)² + (a₂ − b₂)² = |a|² + |b|² − 2(a₁b₁ + a₂b₂)。比較兩式，就得到 |a||b|cos θ = a₁b₁ + a₂b₂。

二、內積的性質

  • 交換律：a·b = b·a。分配律：a·(b + c) = a·b + a·c。係數：(k a)·b = k (a·b)。
  • a·a = |a|²（因為夾角 0°，cos 0° = 1）。所以 |a| = √(a·a)。
  • 展開：|a + b|² = |a|² + 2 a·b + |b|²；|a − b|² = |a|² − 2 a·b + |b|²（像乘法公式）。

三、求夾角與判斷垂直、平行

cosθ夾角 = a向量·b向量|a| × |b|
a·b 的值夾角 θ兩向量的關係
> 0銳角（0° ≤ θ < 90°）大致同方向
= 090°互相垂直（a ⊥ b）
< 0鈍角（90° < θ ≤ 180°）大致反方向
= |a||b|0°平行且同向
= −|a||b|180°平行且反向

最常考的是「垂直」：a ⊥ b ⇔ a·b = 0 ⇔ a₁b₁ + a₂b₂ = 0。

例題：內積與夾角

a = (1, 2)、b = (3, −1)：a·b = 3 − 2 = 1；|a| = √5、|b| = √10；cos θ = 1√5 × √10 = 15√2 = √210（銳角）。

a = (1, √3)、b = (2, 0)：a·b = 2；|a| = 2、|b| = 2；cos θ = 24 = 12，θ = 60°。

例題：垂直

a = (k, 2)、b = (3, −6)，a ⊥ b：3k − 12 = 0 → k = 4。

(2, 3) 與 (3, −2)：6 − 6 = 0，所以互相垂直。

例題：長度的計算

|a| = 3、|b| = 4、夾角 60°：a·b = 3 × 4 × 12 = 6；|a + b|² = 9 + 2 × 6 + 16 = 37，|a + b| = √37。

一句話記住

a·b = |a||b| cos θ = a₁b₁ + a₂b₂；cos θ = a·b ÷ (|a||b|)；垂直 ⇔ a·b = 0；a·a = |a|²。

陷阱

內積的結果是數，不是向量。夾角範圍是 0° 到 180°。a·b = 0 可能是其中一個是零向量，通常題目默認兩個向量都不是零向量。

3-3內積的應用

先搞懂

內積不只是算夾角，還能解決很多幾何問題：一個向量在另一個向量上的「影子」（正射影）、三角形面積、點到直線的距離。物理的「功 = 力 × 位移 × cos 夾角」其實就是內積。

一、正射影

用垂直於 a 的光線照 b，b 落在 a 所在直線上的影子，就是 b 在 a 上的正射影

b 在 a 上的正射影（向量）= a向量·b向量|a|² a向量正射影的長度（有號）= a向量·b向量|a|
  • 有號的長度：正表示影子和 a 同方向（夾角是銳角）；負表示反方向（夾角是鈍角）；0 表示垂直。
  • 這是因為影子長度 = |b| cos θ，而 a·b = |a||b|cos θ，所以 |b|cos θ = a·b ÷ |a|。
例題：正射影

a = (3, 4)、b = (2, 1)：a·b = 6 + 4 = 10，|a|² = 25。正射影向量 = 1025 × (3, 4) = (6／5, 8／5)；有號長度 = 105 = 2。

二、三角形的面積

△ABC 的面積 = 12 |x₁橫分量y₂縱分量 − x₂橫分量y₁縱分量|（AB = (x₁, y₁)、AC = (x₂, y₂)）

面積 = ½|AB||AC| sin θ。因為 sin²θ = 1 − cos²θ，所以 (|a||b| sin θ)² = |a|²|b|² − (a·b)² = (a₁b₂ − a₂b₁)²，開根號就得到上面的公式。

例題：用向量求面積

A(0, 0)、B(4, 0)、C(1, 3)：AB = (4, 0)、AC = (1, 3)，面積 = 12 |4 × 3 − 1 × 0| = 6（底 4、高 3，和直接算一樣）。

三、直線的法向量與點到直線的距離

  • 法向量：和直線垂直的向量。直線 ax + by + c = 0 的法向量是 (a, b)（因為直線上任兩點的差向量 (x₂ − x₁, y₂ − y₁) 滿足 a(x₂ − x₁) + b(y₂ − y₁) = 0）。
  • 方向向量：和直線平行的向量，可取 (b, −a)（和法向量垂直）。
  • 兩條直線的夾角，可以用它們的法向量（或方向向量）的夾角求出。
點 P(x₀橫坐標, y₀縱坐標) 到直線 a係數x + b係數y + c常數 = 0 的距離：d距離 = |a係數x₀橫坐標 + b係數y₀縱坐標 + c常數|√(a係數² + b係數²)

為什麼？在直線上任取一點 Q，PQ 在法向量 n = (a, b) 上的正射影長度，就是 P 到直線的距離，也就是 |n·PQ| ÷ |n|，化簡後就是上面的公式。

例題：點到直線的距離

點 (1, 2) 到直線 3x + 4y − 5 = 0：d = |3 × 1 + 4 × 2 − 5|√(9 + 16) = 65 = 1.2。

四、功與內積（和物理的連結）

力 F 使物體產生位移 s 時，做的功 W = |F||s| cos θ = F·s：只有力在位移方向上的「分量」才有做功。

例題：功

F = (3, 4) N、位移 s = (5, 0) m：W = 3 × 5 + 4 × 0 = 15 J。

一句話記住

正射影長度 = a·b ÷ |a|；面積 = ½|a₁b₂ − a₂b₁|；點到直線 ax + by + c = 0 的距離 = |ax₀ + by₀ + c| ÷ √(a² + b²)；功 = 力 · 位移。

陷阱

正射影有方向：b 在 a 上，和 a 在 b 上不一樣（分母是被投影到的那個向量的長度）。點到直線距離公式的直線必須先整理成 ax + by + c = 0（右邊是 0）。
