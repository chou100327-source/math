1-1實數

數系符號說明與例子

整數Z…, −2, −1, 0, 1, 2, …

循環小數化成分數

類型做法例子
純循環循環節 ÷ 同位數的 90.3 = 3/9 = 1/3；0.12 = 12/99 = 4/33
混循環(全部數字 − 不循環部分) ÷（循環幾位就幾個 9，後面補不循環幾位的 0）0.12 = (12 − 1)/90 = 11/90
帶整數整數部分另外加1.3 = 1 + 1/3 = 4/3

根式運算（a、b > 0）

√a正數 × √b正數 = √(a正數b正數) √a正數 / √b正數 = √(a正數/b正數) 分母有理化：1 / (√a正數 + √b正數) = (√a正數 − √b正數) / (a正數 − b正數) 雙重根號：√(a大的數 + b小的數 ± 2√(a大的數b小的數)) = √a大的數 ± √b小的數

乘法公式

(a第一項 + b第二項)² = a第一項² + 2a第一項b第二項 + b第二項² (a第一項 − b第二項)² = a第一項² − 2a第一項b第二項 + b第二項² (a第一項 + b第二項)(a第一項 − b第二項) = a第一項² − b第二項²
區間寫法意思數線畫法
[a, b]a ≤ x ≤ b（閉區間）兩端實心點
(a, b)a < x < b（開區間）兩端空心點
[a, b)a ≤ x < b左實心、右空心
(a, ∞)x > a無限大那一邊一定用小括號
  • 不等式兩邊同乘（除）負數，不等號要反向。
  • 有理數 + 無理數 = 無理數；但無理數 + 無理數不一定是無理數（√2 + (−√2) = 0）。
例題

化簡 √(5 + 2√6)：找兩數相加 5、相乘 6 → 3 和 2，答案 = √3 + √2。
有理化 1/(√3 − √2) = (√3 + √2)/(3 − 2) = √3 + √2。

陷阱

0.9 = 1。√(a + b) ≠ √a + √b。π 是無理數，3.14 和 22/7 只是近似值。

1-2絕對值與平面直角坐標系

|a實數| = a實數（a ≥ 0）；= −a實數（a < 0） √(a實數²) = |a實數| 數線兩點距離 = |a點A坐標 − b點B坐標|
絕對值方程式／不等式（a > 0）解記法
|x| = ax = a 或 x = −a離原點 a
|x| < a−a < x < a小於夾中間
|x| > ax > a 或 x < −a大於跑兩邊
|x − c| ≤ rc − r ≤ x ≤ c + r以 c 為中心、半徑 r
  • 性質：|ab| = |a||b|；|a + b| ≤ |a| + |b|（三角不等式）；|a| ≥ 0。
  • |x| = −3 無解（絕對值不可能是負數）。

坐標平面

兩點距離 = √((x₂B的x − x₁A的x)² + (y₂B的y − y₁A的y)²) 中點 = ((x₁A的x + x₂B的x)/2, (y₁A的y + y₂B的y)/2) 分點 AP:PB = m前段比:n後段比 → P = ((n後段比x₁A的x + m前段比x₂B的x)/(m前段比+n後段比), (n後段比y₁A的y + m前段比y₂B的y)/(m前段比+n後段比)) 重心 = ((x₁A的x+x₂B的x+x₃C的x)/3, (y₁A的y+y₂B的y+y₃C的y)/3)
象限第一第二第三第四
(x, y) 正負(+, +)(−, +)(−, −)(+, −)
點 (a, b) 的對稱點結果記法
對 x 軸(a, −b)y 變號
對 y 軸(−a, b)x 變號
對原點(−a, −b)兩個都變號
對直線 y = x(b, a)x、y 交換
例題

A(1, 2)、B(4, 6)：距離 = √(3² + 4²) = 5，中點 = (2.5, 4)。
解 |x − 2| < 3：−3 < x − 2 < 3 → −1 < x < 5。

陷阱

在 x 軸或 y 軸上的點不屬於任何象限。分點公式是「比例交叉乘」：靠近 A 的比例 n 乘在 A 的坐標上。

1-3常見的函數圖形

  • 函數：每一個 x 都只對應一個 y。圖形判斷：畫鉛直線，最多只碰到圖形一次。
  • 定義域：x 可以用的範圍；值域：y 得到的範圍。
一次函數：y函數值 = a斜率x自變數 + by截距 斜率 m斜率 = (y₂B的y − y₁A的y) / (x₂B的x − x₁A的x) 常數函數：y函數值 = c常數
一次函數 y = ax + b圖形
a > 0直線往右上升
a < 0直線往右下降
a = 0水平線（常數函數）
b和 y 軸交點 (0, b)

二次函數（拋物線）

一般式：y函數值 = a二次項係數x自變數² + b一次項係數x自變數 + c常數項 配方式：y函數值 = a二次項係數(x自變數 − h頂點x)² + k頂點y 頂點 h頂點x = −b一次項係數 / 2a二次項係數 k頂點y = −(b一次項係數² − 4a二次項係數c常數項) / 4a二次項係數 判別式 D判別式 = b一次項係數² − 4a二次項係數c常數項
看什麼結論
a > 0開口向上，頂點是最低點，最小值 = k
a < 0開口向下，頂點是最高點，最大值 = k
|a| 越大開口越窄
對稱軸x = h = −b/2a
c和 y 軸交點 (0, c)
D > 0和 x 軸交兩點
D = 0和 x 軸相切（交一點，就是頂點）
D < 0和 x 軸不相交
圖形平移由 y = f(x) 變成
向右 h 單位y = f(x − h)（括號裡是減號才是往右）
向上 k 單位y = f(x) + k
例y = 2x² 右移 3、下移 1 → y = 2(x − 3)² − 1，頂點 (3, −1)
  • 絕對值函數 y = |x|：V 字形，頂點在原點，以 y 軸對稱。y = |x − h| + k 的頂點是 (h, k)。
拋物線練習器：拉拉看 a、b、c
例題

y = x² − 4x + 1 配方：y = (x − 2)² − 3。頂點 (2, −3)，對稱軸 x = 2，開口向上，最小值 −3；D = 16 − 4 = 12 > 0，和 x 軸交兩點。

陷阱

y = (x + 2)² 的頂點在 (−2, 0)，不是 (2, 0)。求最大、最小值前先看 a 的正負。

1-4一元二次不等式

先準備：一元二次方程式 ax² + bx + c = 0

公式解 x根 = (−b一次項係數 ± √D判別式) / 2a二次項係數 兩根和 α根1 + β根2 = −b一次項係數 / a二次項係數 兩根積 α根1β根2 = c常數項 / a二次項係數

解題步驟：① 移項，右邊變 0　② 讓 x² 係數變正（乘 −1 時不等號反向）　③ 因式分解或公式解找出兩根 α < β　④ 套下表

（a > 0，兩根 α < β）解記法
(x未知數 − α小根)(x未知數 − β大根) > 0x < α 或 x > β大於跑兩邊
(x未知數 − α小根)(x未知數 − β大根) < 0α < x < β小於夾中間
≥ 0 或 ≤ 0同上，端點也要包含用 ≤ 或 ≥
D > 0：交兩點，>0 解在兩邊，<0 解在中間
D = 0：相切，>0 解為 x ≠ α；≥0 全部實數；<0 無解；≤0 只有 x = α
D < 0：不相交，>0 解為全部實數；<0 無解
恆成立的條件條件
ax² + bx + c > 0 對所有 x 成立（恆正）a > 0 且 D < 0
ax² + bx + c < 0 對所有 x 成立（恆負）a < 0 且 D < 0
例題

解 x² − x − 6 > 0：(x − 3)(x + 2) > 0，兩根 −2、3 → x < −2 或 x > 3。
解 −x² + 4x − 3 ≥ 0：先乘 −1 → x² − 4x + 3 ≤ 0，(x − 1)(x − 3) ≤ 0 → 1 ≤ x ≤ 3。
已知解為 1 < x < 3，反推不等式：(x − 1)(x − 3) < 0 → x² − 4x + 3 < 0。

陷阱

x² 係數是負的時候，一定要先乘 −1 並把不等號反過來，再套「大於兩邊、小於中間」。x² + 1 > 0 的解是所有實數，x² + 1 < 0 無解。
